# ThatGirlNiq — Official Website

A fully responsive, single-page site for **ThatGirlNiq** — comedy, real life, and live virtual shows.

## Content policy

**Every fact, photo, caption, and number on this site comes from the three verified sources only:**

1. TikTok — https://www.tiktok.com/@.thatgirlniq
2. Instagram — https://www.instagram.com/thatgirlniq/
3. Zoom (virtual live shows) — https://us06web.zoom.us/j/85605782390?pwd=wenmJAWbK0PXx13NPGK47czGsj7bnF.1

No stock photos, no invented testimonials, no placeholder copy. If it isn't on one of those three links, it isn't on this site. (Data captured October 2026.)

## Quick start

```bash
npm install
npm run dev        # dev server with hot reload
npm run build      # production build → dist/ (static site, deploy anywhere)
npm run preview    # serve the production build locally
```

## Updating content — one file

Everything editable lives in **`src/data/content.ts`**:

| Field | What it controls |
|---|---|
| `site.instagramBio` / `site.tiktokBio` | Verbatim bios shown in About |
| `site.nextLiveShow` | ISO date string for the Zoom countdown, or `null` = "coming soon" placeholder |
| `stats` | Follower/like/post counts on the Social Proof section |
| `clips` | TikTok embeds (`id` = video id from the post URL, real `caption` + `views` from the post) |
| `igReels` | Instagram reel link cards (`url` = real post URL) |
| `site.heroImage` / `site.aboutImage` | Real photos downloaded from her accounts, stored in `public/assets/` |

### Adding a new TikTok video

1. Copy the video id from the post URL: `tiktok.com/@.thatgirlniq/video/<id>`
2. Add an entry to `clips` with the **real caption and real view count** from the post.
3. The embed, thumbnail, and player are generated by TikTok automatically — no image needed.

### Updating follower counts

Open the TikTok/IG profiles, read the numbers, update `stats` in `content.ts`.

### Setting the next live show

When Niq announces a virtual show date on TikTok/IG, set e.g.
`nextLiveShow: '2026-11-01T20:00:00-05:00'` in `content.ts` — the countdown on the
Live section starts counting automatically. Leave `null` to keep the "coming soon" placeholder.

### Instagram reels

IG thumbnails are **not** hot-linked (their URLs expire within hours). The reel cards are
clean links to the real posts; swap the `url`/`date` fields as new reels drop.

### Analytics

Uncomment the GA4 block in `index.html` and replace `G-XXXXXXXXXX` when going live.

## Stack

React 18 + TypeScript + Vite 7 + Tailwind CSS 3.4. Scroll reveals use `IntersectionObserver`
(`src/hooks/useInView.ts`), the live countdown lives in `src/hooks/useCountdown.ts`,
the dark/light toggle in `src/hooks/useTheme.ts`. Respects `prefers-reduced-motion`.
Videos are official TikTok embeds — no media is re-hosted.
